# My Game Vault

Personal, iPhone-first physical game collection manager for Xbox One, Xbox Series X, and Nintendo Switch.

## Features
- Combined Xbox collection with platform badges
- Separate Nintendo Switch collection
- Universal search
- Two-column cover grid on iPhone
- Detailed game records
- Server-side duplicate protection by title/platform/edition and UPC when available
- Add, edit, and remove games
- JSON backup with merge or replace restore
- Netlify Blobs persistent storage
- Offline shell caching after first load

## Data
No pricing or resale-value data is stored. Collection records include title, platform, edition, UPC, artwork URL, summary, release information, developer/publisher, ESRB, player/co-op information, notes, and date added.

## Local development
Run `npm install`, then `npx netlify dev`.
